# AVELA — E-commerce de Moda & Lifestyle

### Uma experiência de compra moderna, elegante e intuitiva.

A **AVELA** é uma plataforma de e-commerce demonstrativa voltada ao segmento de moda e lifestyle, desenvolvida com foco em **design moderno, responsividade e experiência do usuário (UX/UI)**.

O projeto busca reproduzir a experiência visual e de navegação de uma loja virtual real, combinando uma identidade visual minimalista com uma interface organizada e acessível.

> **Projeto demonstrativo:** Esta loja foi desenvolvida exclusivamente para fins de estudo, prática e composição de portfólio profissional. Não são realizadas vendas ou transações financeiras reais.

---

## Sobre o Projeto

A AVELA nasceu da proposta de criar uma loja virtual com uma identidade visual sofisticada, inspirada em marcas de moda contemporâneas.

O desenvolvimento prioriza três aspectos fundamentais:

- **Design:** identidade visual elegante, minimalista e consistente.
- **Usabilidade:** navegação intuitiva e organização clara dos conteúdos.
- **Responsividade:** adaptação da interface para diferentes tamanhos de tela.

## Funcionalidades

O projeto apresenta os seguintes elementos de interface:

- Página inicial com banner de destaque.
- Menu de navegação por categorias.
- Seções de moda masculina e feminina.
- Áreas dedicadas a novidades, essenciais, ofertas e acessórios.
- Vitrine de produtos e organização visual do catálogo.
- Identidade visual personalizada, incluindo logotipo e favicon.
- Layout pensado para diferentes dispositivos.
- Carrinho de compra
- Tela de login

## Identidade Visual

A identidade da AVELA combina elementos minimalistas e contemporâneos para transmitir elegância, simplicidade e sofisticação.

A proposta visual utiliza tons neutros, tipografia refinada, imagens de moda e uma organização que valoriza os produtos apresentados.

## Objetivo

Este projeto foi desenvolvido para colocar em prática conhecimentos relacionados ao desenvolvimento com React, TypeScript e à construção de experiências digitais voltadas ao comércio eletrônico.

Além da apresentação visual, a AVELA representa uma oportunidade de explorar conceitos de organização de conteúdo, navegação, design responsivo e experiência do usuário.
